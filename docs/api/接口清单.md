# spring-shop 用户端接口清单

> 来源：`http://localhost:6001/v3/api-docs`（OpenAPI 3.1.0，由后端 springdoc 自动生成）
> 服务版本：`v1`（spring-shop API）
> 服务器地址：`http://localhost:6001`
> 范围：仅用户端（前台）接口；管理后台接口不在本文档内
> 接口总数：29 个（23 个路径），涉及数据模型 36 个

## 全局约定

- **鉴权方式**：除注册/登录等公开接口外，均需携带 JWT Token。
  - securityScheme `bearer-jwt`：type=http，scheme=bearer，即请求头 `Authorization: Bearer <token>`
- **统一响应包装**：成功响应统一为 `Result<T>` 结构：

  | 字段 | 类型 | 说明 |
  |---|---|---|
  | code | integer | 业务状态码 |
  | message | string | 提示信息 |
  | data | T | 业务数据 |

- **分页结构**：分页查询的 data 为 `PageResult<XxxVO>`，含记录列表与总数（字段见数据模型附录）。
- **403 响应**：所有接口未认证/无权限时返回 `ResultVoid`（无 data），下文各接口不再单独列出。
